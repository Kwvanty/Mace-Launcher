Mace Launcher
=============
Official website: https://mace-launcher.onrender.com/

Description:
Mace Launcher is a customizable Minecraft launcher developed by Kwvanty.

Main feature:
Full launcher customization.

Minecraft support:
- Multiple Minecraft versions
- Fabric
- Forge
- NeoForge
- Modpacks
- Resource packs
- Shader packs

Current version:
1.0.6

Developer:
Kwvanty — 8th-grade developer and adventurer.

It is safe:
There is no point in hacking you or flooding your device with viruses.
The team simply wants the user to enjoy a comfortable experience.
Project status:
Active development
